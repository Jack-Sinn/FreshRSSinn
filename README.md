# FreshRSSinn

A simple recode of FreshRSS prioritizing **TypeScript**, **SQLite** and **GO** from a majority php application.
- Implement a TypeScript frontend focused on performance and readability.
- Build a Go backend API for feed ingestion, sync, and article delivery.
- Use SQLite as the default embedded database.

## Cosmetic & Quality Changes
- Setup a custom view where whitespace is greatly reduced and articles are compact
- Refresh typography, spacing, and visual hierarchy across the app.

### 3) Embedded video player

- Initial player is vertical
- Support seamless rotation/expansion to full-screen playback when needed.

### 4) Android companion app
- Keeping a the companion app in mind, provide clean api architecture
