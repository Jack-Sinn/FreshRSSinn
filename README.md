# FreshRSSinn

FreshRSSinn is a FreshRSS recode focused on:

- **Go** for backend services
- **SQLite** for lightweight local-first data storage
- **TypeScript** for a modern, maintainable frontend

## Product direction

### 1) Recode foundation (Go + SQLite + TypeScript)

- Build a Go backend API for feed ingestion, sync, and article delivery.
- Use SQLite as the default embedded database.
- Implement a TypeScript frontend focused on performance and readability.

### 2) Compact, modern reading experience

- Modernize layout to reduce wasted whitespace between articles.
- Increase information density while preserving readability.
- Refresh typography, spacing, and visual hierarchy across the app.

### 3) Embedded video player

- Play article videos directly inside the app.
- Player should open at a tall, screen-filling vertical layout first.
- Support seamless rotation/expansion to full-screen playback when needed.

### 4) Android companion app

- Provide a clean, modern Android companion app experience.
- Keep visual language and core interactions aligned with the web app.
